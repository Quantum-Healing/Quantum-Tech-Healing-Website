# Archived videos

These original videos exceed Cloudflare Workers' 25 MiB static asset limit.
They are preserved here outside `Quantum Tech/site`, so they are not deployed.
Git LFS retains the original media; `manifest.json` records their original sizes.

To restore a video later, upload its original media to a video host or R2,
then add its hosted URL to the appropriate testimonial or operator page.
Do not deploy this archive folder as static assets.
